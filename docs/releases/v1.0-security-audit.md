# v1.0 security release audit

This audit checks the frozen v0.9 trust boundaries for stable promotion. It adds
corrective fixes and regression coverage, not a new API, protocol, schema,
capability, validation language, or deployment mode. Package versions remain
unchanged until the release phase.

## Findings and corrective evidence

| Finding | Reproduction and retained regression |
| --- | --- |
| Deep known-version JSON could escape the header parser as `RecursionError`. | A 2,048-level array fits under the encoded and decoded header bounds but crashes the installed v0.9 parser on Python 3.11. The parser now falls back to an empty hint map; both array and object cases return safely. Direct parser and real FastAPI page-request tests run on the supported Python CI matrix. Python 3.13's iterative decoder may retain the valid shallow entry; this compatible behavior is preserved. |
| Initial SSR fetch automatically followed redirects to another origin. | Two real HTTP servers demonstrate the previous request reaching a second origin for each of 301, 302, 303, 307 and 308. The fixed tests assert the second server receives no request. Same-origin relative redirects retain authentication; malformed, credential-bearing and cross-origin targets reject, and loops stop after at most 20 follows. Discarded response bodies are cancelled. |
| A symlink at the configured project boundary itself was not inspected. | Page-only and complete project generation could replace an outside registry through the symlinked root. Both now reject before any write and leave the outside directory and its sentinel unchanged. Existing destination and intermediate-directory symlink checks remain. |
| Forwarding removed standard hop-by-hop names but not additional fields named by `Connection`. | SSR and production transport tests previously observed the nominated fields upstream. The fixed SSR allowlist and both proxy directions remove these fields case-insensitively while preserving end-to-end headers. |

The source fixes belong to the Python header parser and Next adapter/generator.
Core remains framework-neutral, and the public declaration and wire baselines
are not rewritten to accommodate a change.

## Reviewed boundaries and retained gates

| Boundary | Source behavior and executable coverage |
| --- | --- |
| Request metadata | `headers.py` and `capabilities.py` retain known-map byte/count/string bounds, strict base64 decoding, duplicate-key rejection, control-character filtering, bounded only/live-key requests and opaque client IDs. `test_protocol.py`, `test_capabilities.py`, `test_live_stream.py` and `test_integration.py` cover malformed and oversized input and authoritative page reconstruction. |
| Manifest parsing | `schema-manifest.ts` bounds the complete source, JSON depth, aggregate values/strings and collection width. Its data-descriptor snapshot rejects cycles, accessors, hidden/symbol data and hostile inspection traps before semantic validation. `schema-manifest.test.ts` retains exact-boundary and malformed-schema cases. |
| Native validation | `validation/plan.ts` bounds plan construction and evaluation depth, operations, properties and issues, contains throwing inspection traps, detects cycles/references and rejects unsafe regexes before execution. `validation.test.ts` and compiler tests retain deep/wide values, sparse/large arrays, hostile proxies, huge error sets, prototype-sensitive names, malformed plans and bad refs. |
| Validation identities | `_validation_locations.py` resolves aliases and union labels from server declarations and quotes non-identifier segments as data without stringifying unexpected objects. `test_validation_errors.py` checks real nested FastAPI errors, aliases, unsafe names, input non-disclosure and ordinary FastAPI response compatibility. |
| Generated writes | `generate.ts` validates all artifact paths and compiles the complete set before the first write. Each replacement uses an exclusive same-directory temporary file, flush, close and rename. Generator, artifact-contract and adversarial tests cover traversal/absolute escaped destinations, unsafe page names, all artifact symlinks, temporary file/symlink collisions, failed rename and recovery after a later filesystem failure. |
| Scope and cache identity | `scope.py`, `_redis_cache_keys.py` and `_redis_cache_codec.py` encode identity delimiters, hash complete scoped identities, restrict namespace scans and bound/version cache payloads. Scope/cache tests retain anonymous and authenticated boundaries, different users/tenants/custom scopes and malformed cached data. Real Redis tests check independent workers and parent/child namespace isolation. |
| Live authorization and messages | `LiveCoordinator` intersects logical keys with authoritative live page declarations and derives opaque topics from server-owned reusable scopes. Redis messages are byte-bounded and Pydantic-validated; malformed input closes the owned subscription. Coordinator, stream, broker and real Redis tests cover topic isolation, invalid events, connection cleanup, restart and canonical resynchronization. |
| Redirects | Python mutation helpers and Core wire readers retain origin-relative internal redirects and explicit HTTP(S) external navigation. Existing mutation/protocol tests reject browser-normalization escapes. Initial SSR now separately confines HTTP redirect destinations to its configured backend origin. |
| CLI and production | CLI commands use argument arrays and locally installed package-manager executables rather than constructing a shell command from host/path input. Production `ManagedProcess` uses `shell=False` and owns process groups. CLI, frontend, supervisor/process and installed-consumer gates retain hostile argument text, startup/shutdown failures, private-backend topology, minimal health/readiness and clean process-tree shutdown. |
| Next routing and forwarding | Protocol routing remains gated by `X-FluxFast: 1`; encoded transport segments cannot select another backend origin. SSR keeps the default/explicit safe-header allowlist; neither path forwards hop-by-hop fields. Transport, Next config and server tests retain normal-document routing, body/live streaming, header filtering and redacted proxy failures. |

## Repeatable verification

From the repository with dependencies installed:

```bash
pnpm typecheck
pnpm test
pnpm test:python
pnpm test:consumer:production
```

Real Redis coverage requires a dedicated disposable test service. Set its URL,
container name and engine, then run the three integration files:

```bash
FLUXFAST_TEST_REDIS_URL=redis://127.0.0.1:6379/0 \
FLUXFAST_TEST_REDIS_CONTAINER=fluxfast-security-test-redis \
FLUXFAST_TEST_REDIS_CONTAINER_ENGINE=podman \
  .venv/bin/python -m pytest -q \
    python/fluxfast/tests/test_redis_cache_integration.py \
    python/fluxfast/tests/test_live_redis_integration.py \
    python/fluxfast/tests/test_redis_multiworker_integration.py
```

The restart test stops and starts that exact service; never point this command
at shared development or production infrastructure. The `Redis workers`
workflow runs this gate on the supported Redis endpoints. Local verification on
2026-09-14 passed **669** Python tests without Redis enabled and **29** real
Redis 8.10.1 integration tests, including an actual restart, with no integration
skips. The original Python 3.11 malformed-header probe failed; both fixed
nesting probes returned safely. Required CI additionally verifies Python
3.11–3.14 and Node 22/24 on the complete candidate commit.

## Scope and limitations

Authentication, authorization, CSRF, ingress/request-body limits, trusted proxy
configuration and application-specific secret handling remain application
responsibilities. Browser metadata never grants a scope or bypasses FastAPI
dependencies. Generated artifacts are not an authorization mechanism.

Generated replacement is atomic per file, not a transaction across all files.
Malformed inputs and unsafe paths fail before writes; a later filesystem error
may leave earlier complete replacements updated. The new regression verifies
the failed artifact stays intact, temporary cleanup is contained and rerunning
converges, matching the [generated artifact contract](../generated-artifacts.md).
Generation assumes an operator-controlled project tree, not a local attacker
with permission to race ancestor-directory replacement during filesystem calls.

Traversal budgets cannot preempt arbitrary caller-supplied JavaScript code that
never returns, such as a nonterminating proxy trap or refinement. Contained
throwing traps and bounded data traversal are tested; refinements remain
application code. Redis Pub/Sub remains ephemeral, with canonical reads on
reconnect rather than durable event delivery.

This artifact is code-boundary evidence, not independent penetration testing or
a completed stable release. Dependency review, audits, CodeQL, performance,
release-candidate, publishing and post-publish verification remain separate
required plan phases.
